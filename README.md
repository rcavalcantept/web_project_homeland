# De Pátria para Pátria

## Descrição do projeto

Página de destino responsiva da exposição "De Pátria para Pátria", da Galeria de Arte TripleTen, que apresenta as cidades natais de alguns funcionários da TripleTen. A página é composta por:

- um cabeçalho com o logotipo da galeria;
- uma seção de abertura com o título da exposição, o subtítulo e uma fotografia;
- uma seção de introdução com título, citação de Joseph Beuys e texto sobre a exposição;
- um rodapé com os direitos autorais.

O layout se adapta às larguras de tela de 320px, 768px e 1280px definidas no design do Figma, sem rolagem horizontal nas resoluções intermediárias.

## Tecnologias e técnicas utilizadas

- HTML5 semântico (`header`, `main`, `section`, `footer`);
- CSS3 com Flexbox e valores relativos (`%`, `max-width`, `aspect-ratio`, `object-fit`);
- design responsivo com consultas de mídia nos pontos de interrupção de 544px e 1024px;
- fonte Inter conectada localmente com `@font-face` (formato `.woff2`);
- imagens otimizadas (logotipo em `.svg` e fotografia em `.jpg` comprimido);
- metodologia BEM e estrutura de arquivos BEM Flat (`blocks`, `pages`, `vendor`);
- normalize.css para padronizar os estilos entre navegadores;
- publicação no GitHub Pages.
